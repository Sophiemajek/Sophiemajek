## Professional profile
I am an Identity & Access Management (IAM) Analyst with hands-on experience working in cybersecurity operations, where I have been involved in identity lifecycle management, user access provisioning, role-based access control (RBAC), Active Directory administration, access reviews, and security policy implementation.
Through my work, I have gained practical experience supporting Joiner, Mover, and Leaver (JML) processes, managing user identities and permissions, implementing access controls, and documenting IAM activities in alignment with organizational security policies and industry best practices.

Beyond my professional experience, I have independently developed technical projects that demonstrate my ability to configure, secure, troubleshoot, and manage identity infrastructure.

This GitHub portfolio showcases my professional experience, technical implementations, documented security activities, and independent projects, highlighting how I apply IAM principles to strengthen identity security, enforce least-privilege access, and support effective identity governance.
